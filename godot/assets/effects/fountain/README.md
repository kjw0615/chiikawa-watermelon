# 솟아나는 샘 / 음식 분수 수류 v1

하늘색·청록 물기둥 + 상단 몽글몽글한 파도 거품 물보라입니다. 음식은 그려 넣지 않았으며 기존 음식 파티클과 별도 레이어로 사용합니다.

| 파일 | 크기 | 용도 |
|---|---|---|
| water_column.png | 512×1024 RGBA | 아래 중앙에서 솟는 물기둥 |
| splash_cap.png | 1024×512 RGBA | 좌우 부채꼴로 퍼지는 거품·물방울 |
| fountain_combined.png | 512×768 RGBA | 두 레이어를 배치한 간편 사용용 정적 스프라이트 |

모두 투명 PNG이며 애니메이션 시트가 아닙니다. 기본 Sprite2D 혼합 방식으로 사용하세요. Additive는 흰 거품과 색을 날릴 수 있어 기본값으로 권장하지 않습니다.

## 권장 크기와 배치

합성 PNG를 0.5배로 표시하면 캔버스는 256×384이며 실제 수류는 대략 대형 노드 한 개 크기의 범위에 들어옵니다. 실제 노드 텍스처 크기는 실루엣마다 다르므로 최종 크기는 씬에서 검수하세요. `layout.json`의 표시 크기·좌표는 적용 시작값입니다.

- 물기둥 캔버스: 80×240, 좌상단 (88,72).
- 상단 물보라 캔버스: 240×120, 좌상단 (8,32).
- 위 좌표의 기준 부모 캔버스: 256×384. Sprite2D.centered=true이면 캔버스 중심을 더해 position을 잡습니다.
- 분수 발생점은 부모 캔버스 내부 (128,292) 근처입니다. 물기둥 아래 끝의 패딩을 포함한 값이므로 최종 씬에서 바닥과 맞춥니다.
- 음식 파티클은 본체 수류와 분리해 계속 발사하고, 음식이 물 위에 타는 느낌이 필요하면 물보라의 위쪽 경계에서 음식이 통과하도록 렌더 순서를 조절합니다.

소규모 연출 예: 상단 물보라 scale.x를 ±4%, scale.y를 ±3%로 천천히 변형하고, 물기둥은 ±2% 폭 변형을 줍니다. 실제 물 흐름을 담은 프레임 애니메이션은 아니므로 시간에 따른 형태 변화는 코드나 셰이더에서 추가해야 합니다. 물방울 파티클을 별도로 추가할 수 있습니다.

검수 이미지: `assets/source/fountain_water_v1/review.png` (밝은 크림 / 어두운 동굴 톤).
원본·전체 생성 프롬프트·Godot 재내보내기 스크립트도 같은 경로에 보존했습니다.

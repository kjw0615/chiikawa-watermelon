아이템 모션 에셋 v1
==================

각 PNG는 **768×512 RGBA**, 3열×2행, 프레임당 **256×256**, 총 **6프레임**입니다.
좌상단부터 가로 우선으로 0→5 순서입니다. 프레임별 공통 셀을 유지하므로 자동 trim은 하지 마세요.

| 파일 | 동작 | 기본 FPS | 루프 |
|---|---|---:|---|
| usagi_shake.png | 우사기 뒤태, 좌우 엉덩이·꼬리 흔들기 | 10 | true |
| bazaar_ticket.png | 교환권 등장 → 당기기 → 찢어짐 → 분리 | 12 | false |
| rakko_slash.png | 준비 → 발도 → 들어올리기 → 베기 → 후속 동작 → 회복 | 12 | false |

동명 JSON에 크기, 프레임 수, 순서, 루프, 권장 프레임별 duration_ms가 있습니다.
Godot Sprite2D는 hframes=3, vframes=2, frame=0..5로 설정하세요.
JSON은 자동 적용되지 않으며, 가변 타이밍은 AnimationPlayer 또는 SpriteFrames에 옮겨야 합니다.
권장 로컬 기준점은 셀 내부 (128, 240)입니다. Sprite2D의 기본 중앙 원점과는 별도 값입니다.
일회성 모션은 마지막 프레임 후 숨기거나 종료하세요.

검수용 재생 페이지: `../../../../assets/source/item_effects_v1/review.html`
원본·프롬프트·재생 페이지·재현 가능한 기계적 슬라이싱 스크립트는 `assets/source/item_effects_v1/`에 있습니다.
게임 씬/로직 연결은 이번 에셋 제출에 포함되지 않습니다.

우사기 참고 영상은 접근 제한으로 재생 확인하지 못했습니다. 요청에 명시된 뒤태 흔들기 동작과 공식 캐릭터 이미지로 구성했으며, 영상 프레임을 복제한 결과는 아닙니다.

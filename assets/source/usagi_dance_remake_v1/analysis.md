# 우사기 춤 영상 분석 및 재제작

참고: 사용자 제공 `assets/usagi_dance_sample/우사기 엉덩이 흔들기 예시영상.mp4`.
로컬 영상 디코딩 확인: 1920×1080, H.264, 29.97fps, 3.30초, 약 99프레임. 도구는 프로젝트 `.codex-local/video_tools/`에만 설치했으며 외부 작업 폴더는 만들지 않았습니다.

## 모션과 캐릭터

- 첫 0초 부근은 확대/전환이 있으므로 안정된 춤 구간을 참고합니다.
- 약 0.30초의 뒤태와 1.50초 부근 뒤태, 0.50초와 1.70초 부근의 반대쪽 엉덩이 자세가 반복되어 한 주기를 약 1.2초로 추정합니다. 원본의 모든 선화 프레임이 동일하게 반복된다는 뜻은 아닙니다.
- 단순히 뒤통수를 기울이는 춤이 아니라, 넓고 동그란 몸통을 비틀어 엉덩이와 꼬리를 좌우로 보내고, 이어 오른쪽 옆얼굴을 보여주는 짧은 바운스입니다.
- 기존 시트보다 몸통이 크고 머리와 폭이 비슷합니다. 팔은 짧고 말려 있고 발은 매우 짧습니다.
- 꼬리는 매끈한 단추가 아닌 삐죽한 털선이 있는 흰 솜털입니다.
- 원본은 어두운 부드러운 선, 평평한 연노랑 채움, 옆얼굴의 핑크 볼과 작은 눈·입을 사용합니다. 과한 3D 하이라이트는 줄입니다.
- 앞선 사용자 피드백을 유지하여 귀 뒷면에 분홍색을 넣지 않습니다.

## 선택한 6개 키포즈

| 순서 | 원본 근사 시간 | 의도 |
|---|---:|---|
| 0 | 0.30초 | 뒤태, 꼬리가 왼쪽에 보이는 엉덩이 |
| 1 | 0.50초 | 뒤태, 엉덩이가 반대로 비틀려 꼬리가 오른쪽 |
| 2 | 0.70초 | 뒤태에서 오른쪽으로 전환 |
| 3 | 0.90초 | 오른쪽 옆얼굴 |
| 4 | 1.10초 | 옆얼굴 바운스, 귀·상체 기울기 |
| 5 | 1.30초 | 옆얼굴 회복 후 뒤태로 연결 |

`reference/six_keyposes.png`는 이 시간 순서의 영상 추출 이미지를 배열한 참고 보드입니다. 배경과 자막은 참고 자료에만 남기고 생성 에셋에는 넣지 않습니다.

기존 재생기와 호환되는 3열×2행, 256×256, 6프레임을 유지하고, 프레임당 200ms / 5fps로 1.2초 루프를 구성합니다. 기존 10fps는 0.6초에 한 바퀴라 관찰한 원본보다 약 두 배 빠릅니다. JSON은 자동 적용되지 않으므로 `item_system.gd` 우사기 호출의 fps도 5로 변경합니다.

내장 image_gen으로 키포즈 참고 재제작했습니다. 원본 영상 픽셀을 잘라 게임에 넣은 것이 아니며 선화·자세를 프레임 단위로 동일하게 복제하지는 않습니다. 생성 마스터와 프롬프트를 보존하고, Godot exporter는 기계적 축소만 수행합니다.

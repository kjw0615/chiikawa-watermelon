# 바자회 교환권 · 오른쪽 절취선 수정

사용자 요청에 따라 중앙에서 두 동강 나던 모션을 티켓 오른쪽 약 1/4의 작은 검표 조각이 떨어지는 모션으로 수정합니다. 왼쪽 큰 본체에는 교환 화살표 전체를 남기고, 오른쪽 작은 조각만 절취선에서 떼어냅니다.

- 출력: `godot/assets/effects/spritesheets/bazaar_ticket.png`.
- 768×512 RGBA, 3열×2행, 각 256×256, 총 6프레임. 기존 JSON·타이밍·일회성 설정은 유지합니다.
- 순서: 등장 → 완전한 티켓 → 오른쪽 조각 접기 → 절취선 찢기 → 작은 조각 분리 → 작은 조각 우측 아래로 이동.
- 원본 마스터: `assets/source/item_effects_v1/masters/bazaar_ticket.png`도 갱신합니다. 아이템 아이콘은 이미 오른쪽 절취선을 표현하므로 변경하지 않습니다.
- 내장 image_gen 편집, 전체 프롬프트는 `prompt.txt`. Godot `export.gd`는 기계적 축소와 크림 배경 검수 이미지 생성만 수행합니다.
- `before.png`는 수정 전 시트, `review.png`는 수정 후 검수 이미지입니다.
- 이번 생성 편집은 원본과 픽셀 단위로 동일하지 않습니다. 크기·프레임 개수와 표현 의도를 기준으로 검수합니다.

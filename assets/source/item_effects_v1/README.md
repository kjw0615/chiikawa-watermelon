- 사용자 영상: https://www.youtube.com/shorts/crmt2f1jLRo . 웹 요청이 제한되어 영상 재생은 검증하지 못함. 요청에 적힌 뒤태 엉덩이 흔들기 동작 기준으로 제작.

`python assets/source/item_effects_v1/export.py`로 음식과 아틀라스를 재내보냅니다. Pillow 필요.

마스터의 고정 셀 전체를 동일 비율로 축소하므로 포즈별 기준점을 바꾸지 않습니다.

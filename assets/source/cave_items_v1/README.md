# 확정 동굴 맵 레이어 + 아이템 아이콘 4종

게임에 연결할 수 있는 PNG 에셋만 추가한다. 씬·스크립트·충돌체·아이템 기능에는 연결하지 않았다. 동굴 시안은 사용자 최종 통과 상태이며, 이번 작업은 가이드 제거와 레이어 분리 및 아이콘 제작이다.

## 레이어 배치

배경 → 게임 노드 → 전경 순으로 배치한다. 두 맵 PNG는 같은 크기·원점 기준이므로 같은 위치와 같은 배율을 적용한다. Sprite2D를 사용할 경우 양쪽 모두 `centered=false`로 맞추거나, 둘 다 동일한 중앙 기준을 사용한다. 한쪽만 크롭하거나 별도 비율로 늘리지 않는다. 배경 가장자리 알파 뒤에는 화면 기본색을 둔다.

`composite_preview.png`는 배경과 전경을 합성한 검수용 이미지다. 실행 시에는 분리된 두 파일을 사용한다. 청록색 U자 충돌 가이드와 제목·DRAFT·범례 문구를 제거했고, 바위의 자연스러운 청록 반사광과 물빛은 유지했다. 전경 중앙은 여러 높이에서 알파 0임을 검사했다.

1024×1536은 일러스트 캔버스 크기다. 실제 플레이 영역 및 충돌 좌표는 엔진에서 맞춰야 하며 PNG 알파를 그대로 충돌체로 삼는 파일이 아니다. 전경의 바닥/바위가 얼굴을 가리지 않도록 노드 레이어·배율·경계를 함께 확인한다.

## 제작·내보내기

- 창작·가이드 제거·투명 레이어 추출: 내장 image_gen. 실제 프롬프트는 generation.json.
- masters/: 생성된 원본 PNG. 기존 승인 시안 파일은 수정하지 않는다.
- export.gd: Godot Image로 RGBA PNG 저장 및 아이콘을 종횡비를 유지하여 128×128 투명 캔버스에 배치하는 오프라인 내보내기 도구다. 게임 런타임에 포함하지 않는다.
- 재생성: Godot 실행 파일로 `--headless --path <프로젝트>/godot --script <프로젝트>/assets/source/cave_items_v1/export.gd` 실행.
- manifest.json: 최종 출력 크기·알파 범위·투명 픽셀·해시 검수 기록.

모든 출력에 실제 투명 픽셀이 있으며, 맵 레이어는 가장자리/반투명 수면을 포함해 알파값이 255에 미치지 않는 픽셀도 있다. 불투명 PNG를 RGBA 형식으로만 바꾼 파일이 아니다. 아이콘은 128×128에서 직접 확인하고, 두 맵 레이어는 합성해서 선/문구 제거와 경계 연결을 시각 확인했다. 게임 플레이/물리 검증은 이번 에셋 제작 범위에 포함하지 않는다.

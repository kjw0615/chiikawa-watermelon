# 머리 중심 2.5D 프로토타입 에셋 v1

## 산출물 및 사용 범위

Godot 4용 정면 머리 PNG. 내장 image_gen으로 생성한 입체 일러스트이며 실제 3D 모델·노멀맵은 아니다. 광원은 이미지 상단 왼쪽에 이미 구워져 있다. 엔진의 강한 돔 음영을 중복 적용하면 얼굴이 어두워질 수 있으므로 우선 무조명 표시로 확인한다. 기존 에셋은 덮어쓰지 않는다.

캐릭터별 neutral.png(기본), surprised.png(놀람), squash.png(착지 찡그림), happy.png(합체 기쁨)를 사용한다. 기본형도 표정 4종 중 하나다. squash는 표정 이름이며 물리 변형이 아니다. PNG는 투명 RGBA이고 해상도는 manifest.json에 기록한다. 프레임은 생성 결과이므로 완벽한 픽셀 정렬·동일 실루엣을 보장하지 않는다. 충돌체는 neutral의 알파 실루엣으로 고정하고 표정이 바뀔 때 재생성하지 않는다. 실제 표시 크기에 맞춰 캐릭터별 scale/offset을 설정한다.

## 머리 특징과 실루엣 설계

| 캐릭터 | 식별 특징 | 물리/표현 포인트 |
| --- | --- | --- |
| 치이카와 | 흰색 넓고 둥근 볼, 작은 둥근 귀 두 개, 검은 눈과 작은 입, 분홍 볼 | 가장 안정적인 둥근 받침. 귀는 작고 둥글게 단순화 |
| 하치와레 | 흰 볼, 하늘색 정수리/귀, 중앙에서 갈라지는 흰 이마무늬, 짧은 삼각 귀 | 삼각 귀로 기울임·걸림 구분. 귀 끝은 부드럽게 처리 |
| 우사기 | 연노란 둥근 볼, 위로 긴 귀 두 개, 분홍 귀 안쪽, 작은 검은 눈 | 높고 긴 실루엣으로 옆으로 눕는 재미. 귀 사이 골은 충돌 분해 대상 |
| 모몽가 | 흰 볼과 푸른 계열 정수리, 둥글고 넓은 귀, 큰 눈 | 넓은 머리와 볼 부피로 차별화. 머리 에셋에서는 꼬리 제외 |
| 쿠리만쥬 | 크림색 볼과 갈색 정수리, 작고 둥근 귀 | 낮고 넓은 형태, 정수리 색과 표정으로 식별 |
| 랏코 | 흰 털, 볼 옆 털의 돌출, 이마의 특징적인 표식 | 작은 털 가닥은 그림에만 남기고 충돌 외곽은 단순화 |
| 시사 | 연노랑/크림색, 말린 눈썹·귀 주변 장식적인 털 | 컬은 색/면으로 표현, 작은 소용돌이에 충돌을 만들지 않음 |
| 후루혼야(카니) | 분홍색 머리, 게 모양 머리띠 | 머리띠는 별도 장식 레이어로 두고 충돌 포함 여부 별도 결정 |

특징은 [공식 캐릭터 소개](https://www.chiikawaofficial.com/characters)와 프로젝트 단체 그림을 참고한 아트 설계 메모다. 동물 종을 확정하는 설명이 아니다. 기존 a~j 파일과 이름의 전수 대응은 확정하지 않았다. 이번 제작 범위는 앞의 3종이다.

## 사운드

모든 WAV는 직접 수학적으로 합성한 비언어적 효과음이며 기존 애니메이션의 음원/성우 음성은 포함하지 않는다. 44,100Hz / mono / PCM 16-bit. generate_sfx.py로 재생성 가능하다.

| 파일 | 길이 | 트리거 제안 |
| --- | --- | --- |
| sfx/contact_soft.wav | 0.14초 | 일정 충격 이상 접촉. 작은 정지 접촉은 생략 |
| sfx/land_squash.wav | 0.26초 | 강한 착지와 찡그림/스쿼시 |
| sfx/merge_pop.wav | 0.52초 | 일반 합체 |
| sfx/merge_chain.wav | 0.68초 | 짧은 시간 내 연쇄 합체 |

권장 시작값: 접촉음은 개체별 최소 간격 0.1초, 전체 동시 발음 4~6개. BGM은 이번 기본 효과음 범위에 포함하지 않는다. PCM 헤더·길이·피크를 검사했으며 실제 스피커 청취 검수는 별도다.

## 엔진 연동

Sprite2D/텍스처로 가져오고 귀까지 포함한 알파 외곽을 확인한다. 각 캐릭터의 중심은 캔버스 중앙보다 머리 본체 중심을 권장한다. 긴 귀 우사기에 단순 중앙 원점을 쓰면 회전 느낌이 달라질 수 있다. manifest의 제안 pivot은 아트 표시 기준이며 질량중심 검증 결과가 아니다. 프로젝트 파일과 게임 로직 수정은 엔진 담당 범위다.

생성 프롬프트는 prompts.json 및 prompts_expressions.json, 알파·크기·정렬 측정값은 manifest.json, 시각 검수용 비교는 review_contact.png를 참고한다.

## 검수 결과

PNG 12장 모두 RGBA, 알파 범위 0~255. 치이카와/하치와레는 각 1312×1199, 우사기는 1254×1254이며 캐릭터 내부의 4표정 캔버스는 동일하다. alpha >=128 마스크 기준 기본형 대비 표정 실루엣 IoU는 0.9863~0.9949. 미세한 경계 변화가 있으므로 최종 양산용으로 픽셀 일치하는 프레임은 아니다. 비교 시트에서 귀 잘림, 몸/소품 혼입, 표정 누락 없이 3종×4상태를 확인했다. 가장자리 낮은 알파 픽셀까지 물리 외곽으로 채택하지 말고 중간 알파 임계값으로 대표 윤곽을 얻은 후 작은 독립 조각을 제외하는 방식이 적절하다.

# 먼작귀 데굴데굴 섬 · UI 컬러 가이드 v1

따뜻한 크림 종이 위에 연한 핑크·노랑·블루를 얹고, 정보는 부드러운 다크브라운으로 읽히게 한다. 원작 분위기를 참고해 제안한 프로젝트 전용 팔레트이며 공식 지정 색상은 아니다. 이번 제출은 적용용 가이드이며 게임 코드는 변경하지 않는다.

| ink | #59443B | 본문·버튼 글자·기본 아이콘 |
| ink_secondary | #80665A | 설명·단계명·면책 문구 |
| border | #C9AA95 | 패널의 장식 테두리 |

| divider | #E8DCCD | 구분선·게이지 바탕 |
| pink | #F8CCD5 | 시작 버튼·교환권 |

화면 면적은 크림 계열 약 70%, 파스텔 약 25%, 진한 정보·강조 약 5%를 목표로 한다. 검정·흰색의 강한 그림자 대신 #59443B를 12~16% 불투명도로 사용한다. Hex는 기본적으로 불투명 #RRGGBB이며 그림자에만 별도 알파를 적용한다.

## 1. 메인 타이틀

| 요소 | 색상 |
|---|---|
| 배경 | 상단 #EAF4F7 → 하단 #FFF8EB의 아주 완만한 세로 그라데이션 |
| 시작 버튼 기본 / 호버 / 클릭 | #F8CCD5 / #FFE0E6 / #E9A5B5 |
| 시작 버튼 테두리 / 글자 | #8C6557 / #59443B, 모든 상태 동일 |
| 시작 버튼 포커스 | #4D7180 추가 링 2px; 호버와 별도로 표시 |
| 한글 제목 채움 / 외곽선 | #FFF4CC / #59443B |
| 제목 보조 그림자 | #C9AA95, 아래 3px; 진한 분홍 그림자는 사용하지 않음 |
| 영문 부제 리본 배경 / 테두리 / 글자 | #F8CCD5 / #C9AA95 / #59443B |
| 시작 키 안내 / 하단 면책 글자 | #80665A |
| 면책 패널 배경 / 테두리 | #FFFDF7 / #E8DCCD |

한글 제목은 80px 기준 외곽선 5~6px, 버튼 글자는 외곽선 없이 쓴다. 현재 코드의 흰 버튼 글자+진분홍 외곽선, 보라색 막과 진한 검정 그림자를 이 토큰으로 교체하면 화면 간 이질감을 줄일 수 있다. 동굴 그림을 타이틀에 남길 경우 위 배경색 위에 장식으로 10~15%만 비치게 하고, 안내·면책 글자는 불투명 패널에 올린다. 인게임 동굴 일러스트 자체는 유지한다.

## 3. 아이템 버튼 4종

배경에만 작은 색상 차이를 두고, 버튼 테두리는 전부 #8C6557, 글자·비용은 #59443B로 통일한다. 기존 투명 PNG 아이콘은 원색을 유지한다. 아이콘 슬롯은 #FFFDF7 / #C9AA95로 통일한다.

| 아이템 | 기본 배경 | 호버 배경 | 클릭 배경 |
|---|---|---|---|
| ① 우사기 엉덩이 흔들기 | #FFF0BE | #FFF6D9 | #EEDB9D |
| ② 바자회 교환권 | #F8CCD5 | #FFE0E6 | #E9A5B5 |
| ③ 랏코 명검 투하 | #DCEEF5 | #EEF7FA | #BED9E5 |
| ⑤ 음식 분수 | #DFF1EA | #EFF8F3 | #BFDDCF |

- 선택/조준 중: 배경은 클릭색, 외곽선 #4D7180 3px + '조준 중' 문구. 색 이외 상태 표시를 둔다.
- 사용 불가: 배경 #ECE6DD, 테두리 #C5B8A8, 글자 #85786E. 자식 Label·아이콘도 함께 상태 처리한다. 아이콘 전체만 흐리게 만들고 비용 문구까지 안 읽히게 하지 않는다.
- 키 배지: 배경 #59443B, 숫자 #FFFDF7.
- 게이지: 트랙 #E8DCCD, 채움 #BCDCCB, 라벨 #59443B. 충전 완료는 작은 별/외곽선으로 표시한다.

## 가독성 확인과 적용 순서

불투명 sRGB 색상 조합의 대비를 계산했다. 본문 #59443B / 크림 #FFF8EB = 8.59:1, 보조 글자 #80665A / 크림 = 5.01:1, 점수 #76513C / 카드 #FFFDF7 = 6.85:1, 시작 버튼 글자 / 기본 핑크 = 6.30:1, 시작 버튼 글자 / 클릭 핑크 = 4.54:1이다. 이는 지정한 글자·바탕 쌍의 계산값이며 전체 UI 접근성 인증은 아니다. 장식 테두리에는 같은 텍스트 기준을 적용하지 않았다.

클로드 적용 순서: 공통 Theme/토큰 → title_screen.gd → side_panel.gd → skill_bar.gd → main.gd 볼륨/게임오버 → pause_menu.gd. 각 버튼의 normal/hover/pressed/disabled/focus와 자식 Label을 함께 갱신한다. 적용 후 실제 화면에서 작은 글자·동굴 배경 경계·음소거·조준·게이지 부족 상태를 확인한다.

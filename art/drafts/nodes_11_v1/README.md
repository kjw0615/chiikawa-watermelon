## 2.5D 표현 방향

원작 비율과 평면적인 얼굴 선을 우선한다. 머리와 귀에만 얕은 부피·좌상단 조명·은은한 음영을 넣고, 얼굴을 현실적인 동물 주둥이나 인형 눈으로 바꾸지 않는다. 전 단계 정면으로 비교하며 귀·뿔·집게가 프레임에서 잘리지 않도록 한다. 시안의 표시 크기는 비율 비교용이며 실제 단계별 물리 크기는 기존 반지름 17,23,30,37,45,54,64,75,88,102,118과 별도로 추후 조정한다.

## 사용자 검수 항목

- [ ] 11단계 순서와 노드 이름 확인
- [ ] 우사기를 이름 없이도 원작 우사기로 알아볼 수 있는지 확인
- [ ] 각 노드의 귀·눈·입·볼터치·색·장식의 원작 충실도 확인
- [ ] 머리 위주 형태와 2.5D 깊이/외곽선 강도 확인
- [ ] 세이렌의 작은 인어 둘을 머리 부착 장식으로 유지할지 확인
- [ ] 수정 대상은 단계 번호와 부위를 지정해 기록
- [ ] 사용자 통과 기록 후에만 적용 승인

아직 어떤 항목도 사용자 통과로 간주하지 않는다. 이번 범위는 각 노드의 대표 머리 시안 1종이며 4표정 양산·충돌체·게임 연동은 후속 범위다.

## 공식 자료 및 관찰 범위

확인일: 2026-11-13. 아래 공식 이미지를 직접 확인하고 기존 파일과 시각적으로 대조했다. 색·선·얼굴 비율은 이미지 관찰을 바탕으로 한 아트 메모이며 공식 수치 규격은 아니다. 자료 이미지를 게임용 완성 PNG로 전용한 것이 아니라 생성 시안의 식별 기준으로 사용했다.

1. [공식 캐릭터 소개](https://www.chiikawaofficial.com/characters): 치이카와·하치와레·우사기·모몽가·쿠리만쥬·후루혼야·시사·랏코의 도안과 이름.
2. [영화 공식 캐릭터 소개](https://chiikawa.toho-movie.jp/atm/characters.html): 세이렌 및 기존 k.svg와 같은 무늬·머리 위 인어 확인.
3. [공식 마켓 아노코 인형](https://chiikawamarket.jp/products/4589468450122): 흰색 털·단일 이마뿔과 이름 대응.
4. [공식 마켓 데카츠요 마스코트](https://chiikawamarket.jp/products/4582662944336): 노란색 털·두 뿔·붉은 눈·치아·혀와 이름 대응. 상품의 봉제 질감은 생성 스타일 기준에서 제외.
5. [원작자 공식 인터뷰](https://chiikawa.toho-movie.jp/interview/nagano.html): 세이렌 머리가 이누하리코를 모델로 했다는 원작자 설명.

사용한 공식 이미지의 구체 URL은 generation.json에 남기며, 외부 자료 전체를 이 폴더에 재배포하지 않는다. 기존 참조 이미지 파일은 저장소의 legacy_web에 보존되어 있다.

## 제작자 검수 결과

11개 개별 시안의 투명 RGBA·알파 0~255·귀/뿔이 프레임 안에 들어오는지 검사하고, 비교 보드에서 순서·이름·머리 외 부위 혼입·주요 식별 요소를 확인했다. 이 검사는 사용자 검수 통과를 대신하지 않는다. 원작 도안과 비교한 선 굵기·눈/입 크기·귀 길이·볼 빗금·장식 비율은 사용자가 조정할 수 있는 시안 항목으로 남긴다. 게임 동작 테스트는 이 시안 전용 PR의 범위에 포함하지 않는다.

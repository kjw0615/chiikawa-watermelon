# 밥그릇 / 라멘 그릇 맵 시안 v1

**사용자 검수 대기 · 게임 미적용.** `review.png` 한 장에서 외관과 안쪽 충돌 경계 제안을 함께 볼 수 있다.

- 왼쪽 EXTERIOR: 크림색 도자기, 분홍 테두리, 옅은 파란 받침과 치이카와 얼굴 장식. 부드러운 2.5D 음영을 적용한 그릇 외관.
- 오른쪽 COLLISION REVIEW: 앞 벽을 걷어낸 검수용 단면. **청록색 U자 선이 안쪽 충돌 경계 제안**이며 입구 위쪽은 열려 있다.
- 작은 U자 도식: 넓은 입구 → 완만하게 좁아지는 벽 → 둥근 바닥 모서리와 짧은 평지. 아래 방향 화살표는 노드 낙하 방향.
- 청록색 안내선·접점 표시·오른쪽 작은 도식은 설명용이며 실제 충돌체에 포함하지 않는다. 장식·그릇 받침·타원형 입구의 원근 표현도 충돌 경계가 아니다.

## 검수 포인트

1. 파스텔톤과 치이카와 감성, 머리 노드와 어울리는 외관인지.
2. 입구 폭과 그릇 깊이, 하단 폭이 쌓기 맵으로 적절해 보이는지.
3. 중앙으로 과하게 몰리지 않도록 평평한 바닥을 둔 형태가 적절한지.
4. 청록색 안쪽 경계와 그릇 일러스트가 자연스럽게 맞물리는지.

표시된 선은 시각 검수용 개념선이다. Godot 충돌 좌표·노드 수용량·귀/뿔 끼임·밸런스는 아직 구현하거나 검증하지 않았다. 사용자 통과 뒤 실제 화면 비율에 맞춰 경계와 전경/배경 레이어를 별도로 제작한다. 이 작업은 `godot/`와 기존 아트에 연결하지 않는다.

## 제작 기록

내장 image_gen으로 생성한 PNG를 변형 없이 저장했다. 실제 프롬프트와 생성 방식은 `generation.json`에 기록한다. 이미지는 검수 보드이므로 배경·제목·설명선을 포함하며, 그대로 게임용 텍스처로 사용하는 파일은 아니다.

# 세이렌의 섬 동굴 틈새 맵 시안 v1

**사용자 검수 대기 · 게임 미적용.** 밥그릇안을 대체하는 세로형 해안/해저 절벽 동굴 콘셉트다. `review.png` 한 장에서 동굴 외관과 청록색 안쪽 충돌 경계를 함께 검수한다. 최종안은 세로 공간을 크게 보여주는 단일 전면 구도다.

추적: [Issue #4](https://github.com/kjw0615/chiikawa-watermelon/issues/4). 시안 제출만으로 종료하지 않고 사용자 검수·후속 적용 확인까지 열린 상태로 유지한다.

## 형태와 연출 기준

- 위가 열린 깊은 세로 틈새. 지붕·가로 아치·종유석이 낙하 입구를 막지 않는다.
- 양옆은 넓고 완만한 곡면이며 바닥 부근에서도 폭을 유지한다. 끼임을 유발하기 쉬운 선반·돌출 턱·가느다란 홈·V자 바닥을 피한다.
- 하단은 넓고 평평한 바위 바닥, 모서리만 부드럽게 연결한다. 최대 노드를 위한 양쪽 여유 폭을 우선한다.
- 어스름한 남보라/청회색 바위, 젖은 청록 반사광, 은은한 바다 안개. 얼굴 노드가 보일 내부는 바깥 바위보다 밝고 질감을 절제한다.
- 물결과 물가는 바닥 아래쪽/전경의 배경 연출이다. 플레이 공간에 물리 수면·부력·장애물을 추가하는 제안이 아니다.

## 청록색 선과 크기 표기

청록색 열린 U자 선만 안쪽 충돌 경계의 시각 제안이다. 위쪽은 닫지 않고 바닥까지 이어진다. 최종 이미지에는 별도 치수 도식이나 노드 크기 원을 넣지 않았다.

현재 `godot/scripts/main.gd`에서 좌우 경계는 L=40, R=440이므로 폭 400, 위험선 TOP_Y=120부터 FLOOR_Y=700까지 높이 580이다. 이번 시안은 이 **폭:높이=400:580**을 내부 공간 설계 기준으로 사용한다. 드롭 위치 y=60에서 위험선까지의 대기/낙하 구간은 이 높이 표기에 포함하지 않는다.

최대 단계 반지름 118의 지름 **236**을 하단 여유의 설계 참고값으로 삼았다. 실제 머리는 비정형이므로 이 값만으로 통과를 보증하지 않는다. 최종 생성 프롬프트에는 위 비율에 가까운 세로 공간과 하단 폭을 입구의 85% 이상 유지하도록 요청했다. 일러스트 비율은 검수용 근사이며 정확한 게임 좌표/스케일과 최대 노드 실제 실루엣은 사용자 통과 후 맞춰 검증해야 한다.

## 검수 항목

1. 기존 게임에 어울리는 충분한 세로 깊이가 보이는지.
2. 최대 노드와 긴 귀 노드를 수용할 하단 폭과 모서리가 적절해 보이는지.
3. 충돌선과 바위 안쪽 모양이 일치하고 노드 접촉 지점을 읽을 수 있는지.
4. 어스름한 동굴 분위기와 작은 얼굴 노드의 가독성이 양립하는지.
5. 물가가 바닥과 낙하 공간을 혼동시키지 않는지.

원작의 특정 동굴 장면을 복제하거나 공식 배경을 확정한 자료가 아니라, 사용자가 선택한 세이렌 섬 동굴 콘셉트를 바탕으로 한 창작 시안이다. 실제 Godot 충돌 좌표·노드 수용량·귀/뿔 끼임·물리 밸런스는 미구현/미검증이며 사용자 통과 뒤 별도 제작한다.

## 제작 기록

내장 image_gen으로 생성하고 개별 PNG는 변형 없이 보존한다. 배경과 설명선이 있는 검수 보드이며 완성 게임 텍스처가 아니다. 실제 프롬프트는 `generation.json`에 저장한다.

브랜치: `feat/codex-cave-map-v1`. 수정 범위는 이 시안 폴더로 제한하고 게임 코드/아트 연결은 변경하지 않는다.

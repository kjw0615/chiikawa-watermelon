## 2. 재미의 중심

캐릭터 외형이 쌓이는 방식과 표정이 연결되면 좋겠다. 긴 귀가 눕혀지며 공간을 만들고, 넓은 몸이 받침이 되고, 비대칭 몸이 기울어져 예상 밖 연쇄 합체를 만드는 식이다. 몸 형태만 보고 무게중심과 안정성을 짐작할 수 있어야 퍼즐로 납득된다. 모든 귀·털·소품에 충돌을 주기보다, 핵심 몸통 외곽과 굵은 돌출부만 게임에 참여시키자.

## 3. 비주얼·표정·연출

- 표정: 평상시 / 낙하 놀람 / 강한 착지 찡그림 / 합체 기쁨 4상태부터 제작. 안정적으로 쉬면 눈 깜빡임, 뒤집히면 어리둥절, 위험선 부근에서는 땀방울을 추가. 눌림 표정은 실제 접촉·하중 추정값과 연결하고 짧은 접촉마다 깜빡이지 않도록 유지시간을 둔다.
- 스쿼시: 착지 순간 접촉 방향으로 납작해졌다가 복원되고, 귀·꼬리는 조금 늦게 흔들린다. 초기에는 강체 충돌체를 유지하고 그림만 작게 변형하는 방식을 제안. 접점 부근을 변형 기준으로 잡고 얼굴은 덜 찌그러뜨려 표정과 물리 위치를 읽기 쉽게 한다. 변형 때문에 실제로 좁은 틈을 통과하는 소프트바디 규칙은 별도 실험 후 결정한다.
- 합체: 접촉 지점에서 짧은 반짝임 → 두 캐릭터가 모이는 잔상 → 새 실루엣이 통통 튀며 등장. 판독성을 위해 효과는 짧고 국소적으로 유지하고 물리 판정은 지연시키지 않는다. 연쇄 합체는 별/음계가 누적되며, 최종 단계는 짧은 축하 연출을 준다.
- 퍼즐 가독성: 외곽선 굵기·그림자·색조를 통일하고, 선택한 캐릭터와 다음 캐릭터는 실제 실루엣으로 표시. 낙하 가이드는 첫 접촉 예상 위치 정도로 제한한다. 몸통의 충돌 윤곽과 그림이 어긋나는 부분은 제작 단계에서 확인한다.
- 화면 분위기: 원본의 파스텔·크림색·손그림 질감을 잇는 작은 장난감 상자 분위기. 흔들림·섬광은 약하게, 감소 옵션 제공. 위험 상황은 캐릭터의 걱정 표정과 박스 가장자리 변화로 알려준다.

## 4. 사운드

- 접촉: 약한 충돌은 작은 톡, 강한 착지는 말랑한 퐁. 크기·충격량에 따라 음높이/볼륨을 달리하되 작은 정지 접촉음은 생략하고 동시 재생 수와 재생 간격을 제한한다.
- 합체: 기본 팝 + 캐릭터 크기에 맞는 짧은 음색. 연쇄 시 같은 음계 안에서 상승해 귀로도 콤보를 알 수 있게 한다. 최종 합체는 별도 짧은 징글.
- BGM: 느긋한 장난감 악기 계열 루프. 위험 시 짧은 리듬층이 추가되고 합체 징글 때 살짝 줄어드는 구성 제안. 반복 음성은 MVP 뒤로 미루고, 먼저 비언어적 새 녹음/합성 효과음으로 감정을 전달한다.

## 5. 제작 우선순위

1. 서로 다른 형태 3종(둥근 몸 / 긴 귀 / 넓거나 비대칭 몸)을 전신 투명 에셋으로 준비해 쌓기·회전·뒤집힘·합체 가독성을 확인한다.
2. 공통 산출물: 몸/표정/귀·꼬리 레이어, 동일한 선·색 기준, 캐릭터별 기준점·몸 크기·충돌 외곽 가이드. 얼굴 파츠가 지워진 몸 베이스를 만들어야 기존 얼굴과 중복되지 않는다.
3. 각 4표정 + 착지 스쿼시 1종 + 합체 효과 1종 + 접촉/합체 효과음부터 붙인다. 원본 256px 원형 초상은 전신 제작 원본으로는 부족하므로 더 큰 작업 원본에서 출력한다.
4. 3종 실험이 재미있고 외형과 충돌이 맞으면 11단계로 확장한다. 엔진이 어느 쪽으로 정해져도 재사용할 수 있게 이미지·효과음과 캐릭터 설정표를 따로 관리한다.

기획 결론: 우선 투자할 부분은 엔진 장식보다 전신 실루엣 3종과 접촉 반응이다. 실제 형태가 만들어내는 쌓기와 그 상황에 반응하는 표정을 먼저 검증하자.

# 먼작귀 데굴데굴 섬 (Chiikawa Tumble Island)

치이카와(먼작귀) 캐릭터로 즐기는 수박 게임(Suika) 스타일 물리 퍼즐 게임입니다. Godot 4.7, GL Compatibility로 만들었고 Windows 실행 파일과 웹 버전으로 배포합니다.

> 비영리 팬메이드 게임입니다. Chiikawa의 모든 권리는 Nagano 및 치이카와 제작위원회에 귀속됩니다.

## 게임 소개
같은 캐릭터 노드 두 개를 부딪혀 합치면 다음 단계로 진화합니다. 노드가 위쪽 선을 넘은 채로 쌓이면 게임 오버입니다.

## 주요 기능
- **11단계 노드 진화**: 치이카와부터 11단계까지 진화합니다. 11단계끼리 합치면 사라지고 +100점입니다.
- **4종 스킬 아이템**: 합체할 때마다 게이지가 찹니다(1~5단계 합체 5%, 6단계 이상 15%). 게이지를 소모해 아이템을 씁니다.
  | 키 | 아이템 | 효과 | 비용 |
  |---|---|---|---|
  | 1 | 우사기 엉덩이 흔들기 | 쌓인 노드를 좌우로 흔듭니다 | 50% |
  | 2 | 바자회의 캐릭터 교체권 | 들고 있는 노드를 다른 노드로 바꿉니다 | 30% |
  | 3 | 랏코의 명검 투하 | 조준한 위치의 노드를 없앱니다 | 100% |
  | 4 | 음식 분수 | 3초 동안 노드를 위로 밀어 올립니다 | 80% |
- **Supabase 계정과 랭킹**: 아이디(닉네임)+비밀번호로 회원가입/로그인하고, 최고 점수가 서버 랭킹에 등록됩니다. 비로그인으로도 플레이할 수 있지만 점수는 저장되지 않습니다. 비밀번호 재설정(아이디+이메일 확인)을 지원합니다.
- **사운드**: BGM(인게임 루프)과 효과음을 따로 조절하는 설정 창, 아이템 효과음.
- **크레딧**: 설정 창의 크레딧 버튼.

## 조작법
| 입력 | 동작 |
|---|---|
| 마우스 이동 / 누른 채 이동 | 노드를 떨어뜨릴 위치 정하기 |
| 마우스 놓기 | 노드 떨어뜨리기 |
| 숫자키 1~4 또는 스킬 버튼 | 아이템 사용 |
| 명검 조준 중 우클릭 / ESC | 조준 취소 |
| ESC | 일시정지 메뉴(소리 조절, 메인으로) |

## 실행과 빌드
- 프로젝트: `godot/` (Godot 4.7.2). 메인 씬 `res://scenes/main.tscn`.
- 내보내기: 프리셋 `Windows Desktop`(`godot/build/ChiikawaTumbleIsland.exe` + `.pck`), `Web`(`CTI_웹버전/`, 별도 저장소 [chiikawa-tumble-island](https://github.com/kjw0615/chiikawa-tumble-island)).
- 자체 테스트(헤드리스, 무음): `godot --headless --path godot -- --verify`, `--title-test`, `--text-audit`.
- 서버 설정은 `godot/data/supabase.cfg`(프로젝트 URL과 publishable key만 포함). 테이블/함수 SQL은 `supabase/`.
